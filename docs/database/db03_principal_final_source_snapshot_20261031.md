# Principal final-review source snapshot (inactive)

The current admission application is a DRAFT, with separate current identity attestation and independently reviewed document clearance. Final Finance clearance, Principal admission decision, READY handoff and D1 `student.create` are absent. This increment composes the two existing sources into a private, read-only snapshot for future final-review work, without treating either as a final admission decision.

`db03_principal_final_source_snapshot(application)` returns the current application version and stage epoch, School/Campus/year, exact current Person attestation and current document clearance identifiers when valid. It checks the retained attestation and document approval command receipts, original Person version and active context. The existing S8 clearance verifier rechecks the latest forwarded required certificates, independently verified original bytes, current reviewer authority, file version/state and deadlines. If a document is quarantined or rejected, the clearance reference is not returned. A missing, withdrawn or inactive-context application returns SQL NULL.

The result always records `finance_clearance_current=false`, `principal_final_approval_recorded=false` and `can_finalize=false`. It creates no final submission, Student, fee, clearance or Principal approval. Only the schema owner may call it; a narrow EXECUTE grant lets that owner invoke the existing workflow-owned S8 clearance verifier, with no client or worker grant. The snapshot is not an authorization token: a future final command must acquire the jointly accepted cross-domain locks, reauthorize its own Principal action and recheck identity, documents, assessment/offer policy and Finance reversal status in that same transaction.

Source order: Foundation, DB03 S1–S10, then this compositional reader. The scholarship stack may install it after S20 as an independent S21 draft. The SQL is non-executable; no production operation, policy, permission or hosted database change is made.

Disposable acceptance adds ten privilege/structure checks, a failed-install rollback probe, and real Auth document-service cases: missing sources, current independently approved documents with missing identity/Finance, later file quarantine, and a rejected required certificate. The established Admissions/Finance/Scholarship regression suite remains in place. This is one prerequisite in the final admission chain, not completion of that chain.
