# DB03 initial assessment stage outcome source (inactive draft)

This proposal adds the private `admission_stage_outcomes` source for a single initial test or interview result. A row must reference the exact assessment for the same application and policy stage through a composite foreign key. Its outcome must match the examiner's explicit PASSED or FAILED result, the latest document intake and published required stage, current application version and stage epoch. A row lock on the application serializes source insertion. Revision 1 is immutable; a future revision protocol needs separate review. The table has forced RLS and no direct client, worker, workflow executor or service-role grants.

This is structural source only. No evaluator can issue a stage outcome yet. In particular, a FAILED assessment cannot become SKIPPED, and a published policy's SKIPPED configuration does not issue an administration exception. Administration's REQUIRED test skip needs a different requester and reviewer, the real Foundation APPROVED to EXECUTED transition, and an atomic applied effect. Neither this source nor the examiner command issues that effect. Document, Approval and Finance stage outcomes are out of this narrow source; final Principal approval and Student creation remain gated.

The SQL stays `.sql.draft`, with no customer operation, production permission seed, executable migration or hosted change. The disposable DB03 runner checks failed-install rollback and 12 pgTAP structural/privilege assertions after installing the assessment source and command. A protected evaluator with real Auth, receipt, audit/outbox and source-current checks is the next implementation step.
