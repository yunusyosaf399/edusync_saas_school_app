# DB08 F9: school review of a parent's bank slip (inactive candidate)

F9 follows the F8 pending bank transfer submission. A verified school staff member with a current, explicit `payment.evidence.review` grant scoped to the submission's Campus can inspect the original private PDF/image and record one immutable `APPROVE`, `REJECT`, or `REQUEST_CORRECTION` decision with a reason. The file worker authenticates the user through Supabase Auth, obtains checked metadata from a private database function, reads the allowlisted archive key, and compares the actual bytes, MIME, size and SHA-256 before recording a decision. The database repeats live authority, source and digest checks at commit time. No public client RPC or table write is granted.

The decision has exact-key replay, an immutable command receipt, audit and outbox records. A changed key cannot replace the first decision. Competing approval of the same School, method, bank and reference is serialized and denied. A parent cannot review their own slip; a staff grant for another Campus cannot view or decide it. Rejection and correction requests preserve the original submission and proof. A correction is a later, separately checked submission referencing the original; it is outside this increment.

`APPROVE` means **verified evidence**. It does not create `finance_official_payments`, assign a receipt serial, allocate a fee, mark an obligation paid, or issue admission clearance. F7 reserves those effects for later checked commands. No hosted database is changed, no permission is seeded by this candidate, and the PR remains draft.

Acceptance on the disposable stack installs F9 after F1–F8 with an injected-install rollback, checks worker-only grants and forced RLS, then uses real Auth family and staff sessions plus the private archive to prove original-byte inspection, family denial, one review, exact replay, a second-decision denial, and absence of an official payment. Production activation still needs storage and IAM wiring, operational recovery and upgrade checks, and separate release approval.
